## 执行约束和验证边界

- 移除的站点不会出现在批量列表里；历史保存的勾选项会被过滤；直接发送队列启动消息也不能打开这些站点。
- 自动提交前检查付费按钮、选中的付费收录方案及必填反链 / 徽章字段。产品自身的 Free / Freemium / Paid 收费模式不属于收录费用。
- 10015 Tools 和 TinyLaunchpad 使用人工确认模式：即使全局开启自动提交，也不会自动点击最终提交按钮。TinyLaunchpad 的新适配使用通用字段识别，登录后复杂控件仍需实际复核。
- 本地集成测试验证真实适配配置在模拟表单上的行为，不能代替真实站点登录、验证码、审核和成功收录验证。
- 站点会调整价格和表单。Cloudflare 或登录限制导致无法核实的步骤已在表中说明，没有将模拟测试结果当作真实收录成功。
